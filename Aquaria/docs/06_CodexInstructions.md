# Instrucciones para Codex

Antes de cada tarea:

1. Leer `README.md` y la documentación relevante de `docs/`.
2. Inspeccionar el repositorio, la versión de Unity, paquetes y cambios pendientes.
3. Buscar sistemas, escenas y nombres existentes antes de crear contenido.

Durante el trabajo:

- No duplicar sistemas ni instalar o actualizar paquetes sin autorización.
- No cambiar Unity, URP, Quality, Player Settings o plataformas sin autorización.
- Hacer cambios pequeños, relacionados con la tarea y compatibles con Android/iOS.
- Preservar `.meta` y assets de plantilla salvo decisión explícita.
- No implementar abstracciones o servicios sin caso de uso actual.

Al entregar:

- Explicar cada archivo creado o modificado.
- Ejecutar las validaciones disponibles y revisar `git diff`/`git status`.
- No afirmar que Unity compiló si no se ejecutó una importación o compilación válida.
- Indicar pasos manuales exactos cuando se necesite el Unity Editor.

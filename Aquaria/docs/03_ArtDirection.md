# Dirección de arte

La dirección inicial apunta a una estética semi-realista o 2.5D premium: agua,
peces y plantas reconocibles, con simplificación deliberada para móvil.

## Principios

- Ambiente zen mediante composición, movimiento contenido y una paleta coherente.
- Siluetas, contraste y estados importantes legibles en pantallas pequeñas.
- Escala, materiales, iluminación y densidad visual consistentes entre assets.
- Interfaz discreta que no compita con el acuario.
- Presupuestos de geometría, texturas, transparencias y efectos definidos antes de producción.

El MVP evitará hiperrealismo, simulación gráfica costosa y assets cuya calidad dependa
de hardware de gama alta. La guía visual concreta se definirá tras pruebas de estilo.
